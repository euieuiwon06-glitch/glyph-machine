# GLYPH MACHINE

웹캠으로 상반신 움직임을 읽어, 그 흔적만으로 한 장의 그래픽 포스터를 쌓아 가는 웹 작업.
화면에는 카메라 영상도 사람도 나오지 않고 움직임의 결과만 남는다.

## 실행

```
npm install
npm run dev        # http://localhost:5317
```
Windows에서는 `run.bat` 더블클릭. 접속하면 브라우저가 카메라 권한을 묻고, 허용하면 바로 움직임 분석이 시작된다.
권한을 거부하거나 카메라가 없으면 마우스로 그리는 대체 모드로 바뀐다.

배포: `npm run build` → `dist/`(정적 파일). Vercel에서는 Framework = Vite, Output = `dist` 그대로.

## 움직임 → 그래픽

정해진 그림을 채우지 않는다. 손이 움직이는 그 순간 그 자리에 바로 그려지고(26px마다 한 조각), 레퍼런스의 조형 언어로 번역된다.
흰 화면에서 시작하고(축선 없음), 쌓일수록 중앙에 모인 기하학적 추상화가 된다.

| 움직임 | 결과 |
|---|---|
| 손이 지나가는 길 | 납작한 펜촉 획: 펜을 내렸다 들었다 하며, 쓰는 구간의 궤적을 축소해 22.5° 단위로 각진 작은 글리프로 쓴다(방향에 따라 굵기 변화) + 옅은 가는 선 0~2가닥 |
| 뾰족하게 접히는 지그재그 | 삼각 면 채움 |
| 가로로 빠르게 긋기 | 길이가 제각각인 가로 막대 줄이 층층이(진행 방향 끝으로 갈수록 짧고 듬성) |
| 선이 모이는 지점 | 무작위 작은 문양(작은 초승달·동심 원호·점선 고리·십자 노드·방사선 다발·점 줄·반원 면) |
| 크게 휘어진 궤적 | 그 원호를 따라 굵은 초승달 면 + 같은 원의 가는 연장선·수평 기준선 (최대 3개, 겹치면 해칭) |
| 빠르고 곧은 궤적 | 끝이 가늘어지는 칼날 면(최대 2개) |
| 빠름 / 느림 | 선이 많고 진함 + 점 사슬·입자 구름 / 선이 적고 옅고 간격이 넓음 |
| 크게 위아래·좌우로 휘두름 | 수직·수평 헤어라인 |
| 양팔 벌림 | 전체 크기·선 묶음 폭 증가, 벌릴 때마다 바깥 점선 원호 |
| 몸·어깨 기울임 | 궤적이 놓이는 좌표계 회전, 선 묶음 비대칭 |
| 고개 끄덕임 | 수직 점 기둥 |
| 멈춤 | 생성 중단. 1초 넘게 멈추면 수렴점에 점이 최대 3개 찍히고 끝 |

질서는 '수렴점'에서 생긴다. 선 묶음은 가까운 수렴점으로 끌려가 모이고, 수렴점은 최대 4개까지 화면 중심 쪽에 생긴다.
선·면·점·입자 수에는 상한이 있고, 이미 빽빽한 칸을 지나는 선 묶음은 흐리게, 더 빽빽하면 생략한다.

## 구조

```
src/engine/elements.ts   그래픽 요소(포스터 좌표 1920×1080의 순수 데이터) + 그리기
src/engine/grammar.ts    STEP 1 정적 재현용 조형 문법(레퍼런스 골격)
src/engine/reference.ts  STEP 1 정적 재현(?ref)
src/engine/composer.ts   손 궤적 → 선 묶음·초승달·칼날·점 사슬 등 생성 규칙, 수렴점, 밀도 제어
src/engine/poster.ts     누적 캔버스(새 요소만 덧그림), 리사이즈 재렌더, 4K 내보내기
src/motion/pose.ts       웹캠 + MediaPipe Pose Landmarker(브라우저 안에서만 추론)
src/motion/features.ts   One Euro 스무딩, 몸 기준 정규화, 속도·각도·거리·대칭·정지 시간
src/motion/mouse.ts      카메라 대체 입력
src/motion/sim.ts        개발용 가상 몸(동작 대본)
```

## 개발용 주소 옵션

- `?ref` — STEP 1 정적 레퍼런스 재현
- `?debug` — 몸 좌표·특징값·생성 통계 패널(카메라 영상은 보이지 않음)
- `?sim` / `?sim=6` — 카메라 없이 가상 몸 대본으로 생성(배속), `&once`는 한 번만 돌고 정지 자세로 끝남
- `?mouse` — 마우스 모드 강제

`scripts/shot.mjs`, `scripts/export.mjs`, `scripts/probe.mjs`, `scripts/camcheck.mjs`는 dev 서버를 띄운 상태에서 헤드리스 Chrome으로 화면·내보내기·정지 동작·카메라 경로를 확인하는 도구.
